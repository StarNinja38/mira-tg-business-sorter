# Чеклист тестирования TG-SORTER (MVP)

Бот @Sort38_bot. Сейчас `Mode=observe` (только наблюдает, авто-ответы выключены).
Проверять по разделам, баги фиксить через `/correct` или сообщать.

## 1. Классификация входящих
- [ ] Спам (крипта/ссылка/«представитель компании») → SPAM, не плодит задачи
- [ ] Деловое сообщение → BUSINESS
- [ ] Короткая болтовня («ок», «где ты») → FRIEND, без LLM-затрат
- [ ] Непонятное >30 симв → UNCLEAR + ❗ «возможно задача» с кнопками
- [ ] Неверную категорию исправить `/correct` → похожее впредь классифицируется верно

## 2. Задачи (главное)
- [ ] Просьба от собеседника («пришли КП до пятницы») → задача через ~10 мин (settle)
- [ ] **Два времени в одном диалоге → ДВЕ задачи** (не одна)
- [ ] **Собеседник рассказывает о СВОих делах** («готовлюсь к экзамену») → задача НЕ создаётся
- [ ] **Ты пообещал помочь** → задача создаётся (на тебя)
- [ ] Время попадает в задачу и в Google Календарь (`YYYY-MM-DDTHH:MM`)
- [ ] Перефразированный повтор той же задачи → НЕ дублируется (нечёткий дедуп)
- [ ] Нет контекста, но есть время → задача с ❓ + бот спрашивает «что это»
- [ ] Перенос даты («давай не в пятницу, а в субботу») → задача обновляется, не дублируется

## 3. Жизненный цикл задачи
- [ ] «скинул / я пришёл / готово» → задача авто-закрывается (Todoist+Notion+уведомление)
- [ ] Просьба о правках («переделай / не то») → задача авто-переоткрывается
- [ ] Кнопки [✅ Выполнено][🗑 Удалить] под задачей работают; при сбое API — не врёт «выполнено»

## 4. Медиа
- [ ] Голосовое/кружок → транскрипт в контексте
- [ ] **Одинаковое фото дважды → второй раз НЕ анализируется** (дедуп), не дублируется в Saved
- [ ] Фото с условиями → Vision вытаскивает суть; оригинал в Saved
- [ ] Документ (PDF/DOCX) → текст извлечён, файл в Saved
- [ ] Лимит 30 фото/день; голос >5 мин → в Saved без транскрипции

## 5. Память / контакты
- [ ] Новый человек → профиль появляется в Notion и Obsidian (после синка ≤15 мин)
- [ ] Бот корректно определяет роль из переписки (не выдумывает родство)
- [ ] Факты и «твои обязательства» накапливаются в карточке
- [ ] Notion: дайджест + полное резюме + последние 5 сообщений + «Открытых задач» + relation на задачи
- [ ] Obsidian: вся история + бэклинки `[[@user]]` + секция «📋 Задачи»
- [ ] Дублей контактов нет; пустых карточек нет; эмодзи-имена не попадают

## 6. Ссылки / сохранения
- [ ] Ссылка из сообщения → сохраняется, видна в `/links`
- [ ] Одинаковый URL от одного человека дважды → НЕ дублируется

## 7. Бюджет / надёжность
- [ ] `/stats` и `/credits` показывают расход/остаток
- [ ] При превышении `ANTHROPIC_MONTHLY_BUDGET` → стоп-кран LLM + алерт
- [ ] Сбой Anthropic/Todoist/Notion → алерт владельцу (не чаще 1/час)
- [ ] Рестарт бота не теряет сообщения, не шлёт дайджест повторно

## 8. Дайджесты (по времени, МСК)
- [ ] 09:00 утренний дайджест · 10:00 дожимание · 20:00 напоминание · Вс отчёт · 04:00 обслуживание+бэкап

## Опционально (после обкатки)
- [ ] Включить RAG: `pip install fastembed numpy` + `ENABLE_RAG=true` → семантический recall
- [ ] Перевести в `Mode=active` (авто-ответы) когда классификация устаканится
