# 04 — Команды бота

Все команды работают **только для владельца** (проверка по твоему user_id). Доступны в чате с **@Sort38_bot**, есть кнопка-меню ☰.

## Основные

### `/help`
**Меню: все команды по категориям** (статус / контакты / о тебе / посты / проактивность / настройки). Нативное меню `/` тоже содержит все команды.

### `/start`
Приветствие, текущий режим, статистика за сутки, список команд.

### `/credits [сумма]`
Баланс и **расход на Anthropic с разбивкой по моделям** (v2.1). Без аргумента: оценка остатка кредитов + расход за месяц по семействам моделей (Haiku — классификация; Sonnet — извлечение/память/судья/черновики/ask) с токенами in/out, Σ месяц и сегодня. `/credits 4.92` — зафиксировать актуальный баланс из console.anthropic.com (бот вычитает траты с этой даты).
> Учёт единый (v2.1): классификатор (Haiku, `message_log`) + все остальные вызовы (`llm_usage`) по тарифу своей модели. Тот же расход питает стоп-кран бюджета и алерт превышения.

### `/health`
Полный статус системы:
- RAM бота, размер БД, uptime, режим
- Доступность Anthropic API (пинг + latency)
- Расходы: сегодня / месяц / остаток бюджета
- Ссылка на реальный баланс Anthropic Console

### `/stats`
Статистика за 7 дней:
- Количество по категориям (SPAM/BUSINESS/UNCLEAR/FRIEND)
- Средняя latency LLM, токены input/output
- Стоимость **классификатора (Haiku)** — полный расход по всем моделям смотри в `/credits`
- Топ-5 слов в спаме

### `/last [N]`
Последние N сообщений (по умолчанию 10) с категориями и правилами. Для отладки классификатора.
Пример: `/last 20`

## Управление

### `/voice` (и `/voice on|off`)
🎙 **Голосовой дайджест** (v3.2): `/voice` — озвучить сводку голосом сейчас (Silero, локально — приватно). `/voice on` — добавлять голос к утреннему дайджесту, `/voice off` — выключить.

### `/schedule @username [минуты] [today|tomorrow]`
📅 **Подобрать время встречи** (v3.1): бот покажет свободные слоты из календаря → выбираешь → создаёт событие + готовит черновик «Давай {время}?» контакту (отправка только по 📤). Напр.: `/schedule @ivan 60 tomorrow`.

### `/summary @username`
🧠 **Умная память отношений** (v3.0): LLM-сводка — кто это, что ты обещал/что висит, тон, как часто пишет, что помнить при следующем контакте. Не поля, а суть.

### `/insights`
📈 **Аналитика за 30 дней** (v3.0): категории с долями, топ-5 контактов по объёму, сколько задач создано, расход. Rich-таблицы.

### `/rule @username РЕЖИМ`
⚙️ **Правило по контакту** (v3.0): `mute` (не слать уведомления), `never` (не создавать задачи), `vip` (срочное всегда пингует без кулдауна), `task` (внимательнее к задачам от него), `clear` (снять).

### `/radar`
📡 **Радар отношений** (v2.10): один экран — 🧊 остывшие важные контакты (молчат 7+ дней), ⚠️ висящие обещания (что ты обещал и не закрыл), ⏰ деловые без ответа >2 дней. Авто-пуш раз в неделю (вс 18:00). Помогает не терять связи и долги.

### `/promises` (он же `/promised`)
🤝 **Твои обещания** (v3.13; в меню с v3.17.1): список открытых задач-обещаний (`is_commitment=1`) с кнопками ✅ закрыть / 📅 перенести — прямо в боте. Живой источник (открытые задачи, не текст), не протухает. _(До v3.17.1 пункт меню был с кириллицей `/обещания` — Telegram его отклонял с `BOT_COMMAND_INVALID`; теперь латиница `/promises`. Хендлер слушает обе формы.)_

### `/topics`
**Топики в личке** (v2.5, Bot API 9.4): бот разносит уведомления по темам «📋 Задачи / ☀️ Дайджест / 💬 Черновики / 🔴 Срочное» в твоей личке с ботом.
- Сначала включи топик-режим бота: **@BotFather → /mybots → @Sort38_bot → Bot Settings → Topics → Enable**
- Затем `/topics` — бот создаст темы (id хранятся в settings_kv) и подтвердит
- Если топики недоступны/тема удалена — уведомления просто идут обычными сообщениями (ничего не теряется)

### `/owner` (и `/owner add|del ID`)
**Мультиаккаунт (v3.3):** один бот обслуживает несколько твоих Telegram-аккаунтов. Уведомления всегда идут в **основной** аккаунт (`owner_user_id`).
- `/owner` — список аккаунтов-владельцев (основной + вторичные)
- `/owner add ID` — добавить второй аккаунт-владелец
- `/owner del ID` — убрать
- ID второго аккаунта узнать: с него написать **@userinfobot**
- Аккаунт, подключивший бота через Business-соединение, регистрируется автоматически. Требует Telegram **Premium** на втором аккаунте.

### `/mode [observe|active]`
- `/mode` — показать текущий режим
- `/mode observe` — только наблюдение (не отвечает никому)
- `/mode active` — полное поведение (авто-ответы вкл)

### `/drafts [on|off]`
Умные черновики ответов (v2.0):
- `/drafts` — показать статус
- `/drafts on` — на деловое входящее бот шлёт владельцу черновик ответа (отправка контакту только по кнопке)
- `/drafts off` — не предлагать

### `/setreply [текст|off]`
Настройка авто-ответа на BUSINESS:
- `/setreply` — показать текущий шаблон
- `/setreply Спасибо, отвечу завтра` — задать новый
- `/setreply off` — выключить
Работает только в режиме `active`, макс 1 раз на человека в сутки.

### `/correct @username КАТЕГОРИЯ`
Исправить классификацию (дообучение). Категории: `BUSINESS` `FRIEND` `SPAM` `UNCLEAR`.
Пример: `/correct @ivan BUSINESS`
Если FRIEND — добавляет в whitelist.

## Контакты

### `/friend @username`
Добавить в whitelist (бот не будет отвечать как спаму).
Также работает в ответ на пересланное сообщение.

### `/unfriend @username`
Удалить из whitelist.

### `/whitelist`
Список разрешённых (последние 50).

### `/about @username`
**Память на контакт:** имя, тип отношений, зачем пишет, темы, резюме, открытые задачи, история последних сообщений. Если есть фото в памяти — показывается.

### `/whois @username [подсказка]` (v3.27)
**Веб-пробив через Perplexity — ДОПОЛНЕНИЕ к внутренней памяти, не замена.** Публичная справка из открытых источников: кто это, чем занимается, соцсети, город; для компаний — юрлицо/отзывы/признаки скама. С источниками (до 5 ссылок). Работает и по произвольной строке: `/whois Иван Петров сантехник Москва`. Для известного контакта — кнопка **«➕ Дописать в памяти»**: выжимка уходит в секцию «Прочее» с пометкой `ИЗ ИНТЕРНЕТА (дата)` — только по нажатию, автоматически ничего не пишется. Приватность: наружу уходит только имя/username/подсказка — НЕ переписка и НЕ факты память. Требует `PERPLEXITY_API_KEY` в `.env` (без него команда отвечает «выключен»).

**Автопробив новых деловых контактов (v4.1).** При ПЕРВОМ сообщении от контакта, которого классификатор определил как **BUSINESS**, бот сам делает такой же пробив фоном и присылает карточку с той же кнопкой «➕ Дописать в памяти». FRIEND/спам/случайные контакты не трогаются — только момент, когда решается «доверять или нет» новому деловому контакту. Один раз на контакт. В памяти всё так же пишется ТОЛЬКО по кнопке.

### `/setname @username Имя`
**Исправить имя контакта** (бот сам правит память + синк в vault). Берёт только первую строку.
Пример: `/setname @friend_gosha Герман`

### `/addfact @username текст`
**Добавить факт в памяти контакта** (дописывает к фактам, синк в vault). Первая строка.
Пример: `/addfact @friend_gosha брат девушки владельца Ники`

### `/setphoto @username` (с фото)
**Поставить фото в памяти контакта вручную.** Пришли боту **фото с подписью** `/setphoto @user` — или ответь `/setphoto @user` на сообщение с фото. Бот ставит его в памяти: Telegram (`/about`,`/me`), embed в vault. Полезно, когда аватар недоступен (Business API «user not found») или хочешь своё фото.

### `/me` (и `/me build`)
**Память о САМОМ владельце** — бот ведёт его по твоим исходящим сообщениям. С v3.23 — **структурное**: 8 секций (Ключевое · Связи/окружение · Учёба-работа · Характер/стиль · Привычки/быт · Предпочтения · Здоровье/личное · Прочее) + **хронология** + стиль письма. Обновляется раз в день (04:00), хранится как контакт типа `владелец` (в `bot.db` + vault). Стиль подмешивается в черновики ответов → они звучат твоим голосом. `/me build` — пересобрать сейчас.

### `/post <про что>` (с фото) + `/postsign`
**Генератор постов в канал с одобрением.** Пришли боту **фото с подписью** `/post <про что>` (или ответь `/post <про что>` на фото) → бот предложит выбрать стиль (⚡ Коротко / 📋 Подробнее / 😎 Мемно) → сгенерит пост (Claude видит фото) → пришлёт превью с кнопками **[✅ Опубликовать] [🔁 Переделать] [🗑 Отмена]**. ✅ публикует в канал `@St4rNinja38`; 🔁 спросит «что поменять?» и перегенерит; 🗑 отмена. Ничего не публикуется без ✅.
- **`/postsign <текст>`** — задать фикс-подпись (добавляется в конец каждого поста). Без аргумента — показать текущую.

### `/find <слово>`
**Поиск по всей переписке.** Находит кто и когда писал про это.
Пример: `/find коллаб`

### `/links [N | @username]`
**Сохранённые ссылки.** Все ссылки из входящих автоматически попадают в БД.
- `/links` — последние 20
- `/links 50` — последние 50
- `/links @username` — только от этого человека
С иконками категорий (💼 деловая / 👤 личная / ❓ непонятная).

## Подписки (v4.59)

### `/subs` (и `/subs all`, `/subs spent [дней]`)
Rich-таблица подписок: сервис · сумма · период · ближайшее списание · кнопка ✖ (убрать из списка). 🔴 — списание сегодня, 🟡 — в окне напоминания (по умолчанию за 2 дня). Итог в месяц по валютам без конвертации («231,81 $»). `all` — вместе с отменёнными, `spent` — сколько списалось по истории за период (по умолчанию 30 дней). Добавлять, править и отменять — голосом или текстом Мире: «добавь подписку ChatGPT 20$ 5-го», «iCloud списывается 28-го», «отписался от Pixa».

## Виджеты (v4.106–v4.107)

Виджет — карточка-страница прямо в личке с ботом, нажатия внутри работают без перехода в приложение. Подробно — [[03 — Функции]], раздел 31.

> [!warning] С 14.11.2026 Telegram не пускает виджеты от обычных ботов. Пока запрет действует, `/day`, `/habits` и `/market` отвечают тем же содержимым текстом, а `/day` и `/market` ещё и кнопкой «📱 Открыть в приложении» на нужный экран мини-приложения (v4.110–v4.112, [[03 — Функции]] §32).

### `/day` (`/день`)
Виджет «Мой день»: просроченные и сегодняшние задачи с прогрессом «N из M». Нажатие на задачу закрывает её, повторное возвращает, «→» переносит на завтра. После первого раза приходит каждое утро под сводкой.

### `/habits` (`/привычки`)
Виджет «Привычки»: неделя кружками, нажатие отмечает день, серия «🔥 N подряд». Привычки добавляются фразой Мире: «добавь привычку зарядка».

### `/market` (`/рынок`)
Виджет «Рынок»: BTC, ETH, TON, S&P 500, Nasdaq, золото, нефть, доллар с графиками за 1Д, 7Д или 1М. После первого раза приходит утром под сводкой.

### `/call test` (`/звонок test`)
Тестовая карточка звонка (v4.108): статус, таймер, реплики, «Заканчивай», «Положить», быстрые подсказки. Нажатия разыгрывают разговор и никуда не звонят. Пока карточка активна, сообщения в чате уходят в неё подсказкой. Настоящий тестовый звонок — пульт в мини-приложении: карточка приходит сама. Пока виджеты запрещены, карточка не приходит.
