# 07 — Решение проблем

> [!warning] Актуализация v3.22: **Notion ретайрнут** (задачи → Todoist, CRM → Obsidian). Notion-разделы ниже неактуальны, пока Notion отключён — оставлены как история/на случай возврата.

## Бот не отвечает на команды / не видит сообщения

1. Проверь что сервис жив:
   ```bash
   ssh <old-server-ip> "systemctl status tg-sorter"
   ```
2. Если упал — логи покажут причину:
   ```bash
   ssh <old-server-ip> "journalctl -u tg-sorter -n 50"
   ```
3. Перезапуск: `systemctl restart tg-sorter`

## Бот не получает входящие из Telegram

- Проверь что в **Telegram → Настройки → Telegram Business → Чат-боты** подключён @Sort38_bot
- В @BotFather должен быть включён **Secretary Mode** (`/mybots` → бот → Bot Settings → Secretary Mode)
- Бот игнорирует **твои собственные** сообщения и людей из whitelist — это нормально

## ~~Задачи не попадают в Notion~~ (неактуально с v3.22 — Notion ретайрнут)

→ С v3.22 задачи в Notion **не дублируются** (только Todoist + bot.db + Obsidian) — это норма. Раздел — история / на случай возврата Notion (раскомментируешь `NOTION_DATABASE_ID`): тогда бот не подключён к базе как интеграция. Открой базу → ⋯ → **Connections** → Add → «TG Sort Bot». Проверка:
```bash
ssh <old-server-ip> 'source /opt/tg-business-sorter/.env; curl -s -o /dev/null -w "%{http_code}" "https://api.notion.com/v1/databases/$NOTION_DATABASE_ID" -H "Authorization: Bearer $NOTION_TOKEN" -H "Notion-Version: 2022-06-28"'
```
`200` = ок, `404` = нет доступа.

## В Todoist название обрезано («...с»)

→ Это был баг с `@` (Todoist парсит как метку). Исправлен в v1.0. Если появилось снова — проверь что задеплоена свежая `core/actions.py` (там `safe_title = title.replace("@","")`).

## Голосовые не распознаются

- Первое голосовое грузит модель ~9 сек — это нормально
- Голос >5 минут не транскрибируется (по дизайну)
- Проверь faster-whisper: `ssh <old-server-ip> "cd /opt/tg-business-sorter && venv/bin/python3 -c 'import faster_whisper'"`

## Календарь не создаёт события

- Событие создаётся **только если есть время** (не просто дата)
- Проверь доступ сервис-аккаунта к календарю (право «Внесение изменений»)
- Проверь что `gcal-service.json` на месте и `GOOGLE_CALENDAR_ID` в .env

## Vault не обновляется в Obsidian

- launchd синхронизирует раз в 15 мин. Принудительно:
  ```bash
  launchctl kickstart -k gui/$(id -u)/com.tgsorter.vaultsync
  cat /tmp/tg_vault_sync.log; grep -i "not permitted" /tmp/tg_vault_sync_error.log
  ```
- Если «**Operation not permitted**» → агент потерял Full Disk Access. Агент работает на **Homebrew python** (`/opt/homebrew/bin/python3`); выдай FDA на его `Python.app` (Настройки → Конфиденциальность → Полный доступ к диску). Системный CLT-python FDA не берёт (баг macOS) — не использовать.
- После обновления Homebrew python (смена версии в пути) — выдать FDA заново.

## На iPhone/iPad нет волта в Obsidian

- Obsidian iOS открывает волты **только из своего контейнера** `iCloud~md~obsidian/Documents/`. Волт там и лежит (`Claude(Second Brain)`).
- Не появился → iCloud ещё не докачал. Дай время + Wi-Fi, потяни список волтов вниз / переоткрой Obsidian. Mac не должен спать (иначе не выгружает).
- В списке выбирать **«Claude(Second Brain)»** (не старый пустой «Second Brain»).
- Тяжёлые desktop-плагины (smart-*, terminal, excalidraw) на телефоне грузятся долго — для чтения не нужны.

## Дубли задач

- Дедуп: нечёткий по названию за 24ч (`_titles_similar`: пересечение слов + стемминг) + LLM topic-match для открытых задач
- Партиал (создалась одна сторона) теперь регистрируется и виден дедупу (не плодит дубль)
- Авто-импорт ручных Notion-задач при ПЕРВОМ запуске мог создать дубли — одноразово, теперь дедуп по page_id + названию

## Задача с эмодзи не создаётся в Notion (400 «2001 символ»)

→ Исправлено (`util.notion_clamp` режет по UTF-16). Если повторилось — проверь, что задеплоены свежие `core/actions.py` + `core/util.py`.

## Высокий расход API

- Проверь `/stats` — что ест токены
- Профили обновляются каждое 10-е сообщение (можно реже в `core/vault.py`)
- Фото — лимит 30/день (`DAILY_PHOTO_LIMIT`)
- Бюджет: `ANTHROPIC_MONTHLY_BUDGET` в .env

## Виджет не пришёл, карточка пришла текстом

→ Это не сбой бота. С 14.11.2026 Telegram отвечает ботам `INPUT_MEDIA_WIDGET_NOT_ALLOWED` на любой `sendWidget` (v4.110). Бот запоминает отказ на 3 часа и шлёт то же текстом или кнопкой в мини-приложение. Проверить, что запрет ещё действует: `journalctl -u tg-sorter | grep WIDGET_NOT_ALLOWED | tail -3`.
