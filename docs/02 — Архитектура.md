# 02 — Архитектура

> [!warning] Актуализация v3.22: **Notion ретайрнут** — задачи в **Todoist**, CRM в **Obsidian**, встречи в **Google Calendar**. `bot.db` — источник истины (внешние системы = проекции). Строки про создание/синк в Notion ниже — историческая архитектура (отключено в P1a/b).

## Стек технологий

| Технология | Назначение |
|------------|-----------|
| Python 3.12 | язык |
| aiogram 3.28.2 | Telegram Bot API 10.0 (Business, топики, цветные кнопки, tg-time, sendMessageDraft) + raw 10.1 (sendRichMessage) |
| anthropic — **Haiku** (классификация/Vision) + **Sonnet** (`anthropic_model_smart`: извлечение задач, память) | тиринг моделей |
| fastembed (опц., `ENABLE_RAG`) | локальные эмбеддинги для семантического поиска (RAG) |
| aiosqlite | БД (whitelist, логи, vault, задачи) |
| pydantic-settings | конфиг из .env |
| loguru | логи (stdout + ротация файла) |
| tenacity | retry на API |
| psutil | мониторинг RAM в /health |
| aiohttp | запросы к Todoist / Notion API |
| faster-whisper | транскрибация голосовых (локально, бесплатно) |
| pypdf, python-docx | извлечение текста из документов |
| google-api-python-client | Google Calendar |
| systemd | автозапуск на сервере |

## Схема базы данных (SQLite, WAL-режим)

| Таблица | Назначение |
|---------|-----------|
| `whitelist` | разрешённые контакты (друзья, авто-добавленные) |
| `message_log` | лог всех сообщений: категория, правило, токены, стоимость |
| `conversation_state` | счётчик сообщений на контакт |
| `settings_kv` | режим (observe/active), шаблон авто-ответа |
| `conversations` | **VAULT** — полная история переписки (in/out, категория) |
| `contact_profiles` | **VAULT** — профиль контакта (кто, зачем, темы, резюме) |
| `task_sync` | связка задач Todoist↔Notion для синхронизации |
| `notification_log` | анти-спам уведомлений (rate limit) |
| `digest_state` | флаги «дайджест отправлен» (рестарт-безопасно) |
| `saved_links` | сохранённые ссылки (UNIQUE по `user_id+url`) |
| `pending_analysis` | очередь отложенного разбора задач (settle) |
| `processed_media` | дедуп фото/голоса по `file_unique_id` |
| `message_vectors` | эмбеддинги для RAG (если `ENABLE_RAG`) |
| `llm_usage` | учёт токенов не-классификаторных вызовов по моделям (v2.1, для `/credits` и стоп-крана) |
| `corrections` · `processed_updates` | дообучение `/correct` · дедуп апдейтов |
| `draft_style` | примеры стиля владельца для самообучающихся черновиков (v2.8) |
| `task_feedback` | анти-примеры: быстро удалённые задачи = «не задача» (v2.9.1) |

> Поля `contact_profiles`: + `facts` (стабильные факты) + `commitments` (незакрытые обязательства владельца) — память-леджер. Поле `task_sync`: + `topic`, `closed_at`, `calendar_event_id`, `due_date` (v2.2 — дедлайн локально, для пультов), relation на контакт в Notion.
> **Vault-пульты (v2.2):** `sync_vault.py` (Mac) экспортирует `Telegram/_tg-state.json` + пишет `Conversations/` → дашборды Obsidian (`Telegram/Telegram.md`, `00 — CRM-пульт.md`) через DataviewJS. Методичка — скилл `tg-vault`. Прод-БД только read-only.
> Надёжность БД: WAL + `busy_timeout=5000` на боевом соединении, `wal_checkpoint(TRUNCATE)` в обслуживании.

## Тиринг моделей
- **Haiku 4.5** (`anthropic_model` = `claude-haiku-4-5`) — классификация, Vision, судьи «сделано / переоткрыть» (массово, дёшево)
- **Sonnet 5.5** (`anthropic_model_smart` = `claude-sonnet-5-5`, с v4.61; до этого Sonnet 4.5) — извлечение задач, уточнения, память, Мира. Параметры под Claude 5 подставляет `core/llm.adapt_params` (без temperature; фоновым — `between_tools` + effort `SMART_EFFORT`), ответ читается `llm.text_of` по типу блока.
- **Whisper small** — локально, отдельным процессом на каждое голосовое (`core/transcribe_worker.py`, v4.58).

## Фоновые процессы (asyncio)

| Процесс | Интервал | Что делает |
|---------|----------|-----------|
| `start_polling` | постоянно | приём сообщений из Telegram |
| `run_task_settle_loop` | 3 мин | отложенный разбор затихших тредов → задачи, авто-закрытие/переоткрытие |
| `run_sync_loop` | 5 мин | Todoist↔Notion статусы + импорт ручных + реконсиляция контактов |
| `run_digest_loop` | 1 мин (проверка времени) | дайджест 09:00, дожимание 10:00, напоминания 20:00, недельный отчёт (вс 09:00), обслуживание 04:00 |
| `widgets.middleware` | по событию | outer-middleware на `dp.update`: ловит `widget_query` до aiogram и отвечает `answerWidgetQuery` (v4.106) |
| `enrich_profile` | по событию (на Sonnet) | обновление профиля контакта (async task) |

> Фоновые циклы под супервизией: падение цикла логируется (`Background loop DIED`), не молча.
