# 01 — Обзор

> [!info] Текущая версия — **v4.113** (22.11.2026)

GitHub: `StarNinja38/tg-business-sorter`. Источник истины — `bot.db`; задачи в **Todoist**, встречи в **Google Calendar**, CRM и память в **Obsidian-vault**. Notion выпилен в v4.0.

## Что такое бот сейчас

Начинался бот как сортировщик входящих в Telegram Business: отсечь спам, поймать деловое, вытащить задачи. Сейчас это **личный ассистент Mira** для стримера и контент-мейкера: она знает переписки и памяти людей, дела, календарь, почту, соцсети и рынок, пишет владельцу сама по расписанию и по поводу, модерирует чаты стримов и канала. Обращается к владельцу «босс» (`OWNER_ADDRESS`), говорит голосом «подруги» (v4.74).

**Mira.** Единый разговорный цикл с инструментами (Мира-чат 2.0, `core/mira.py`, флаг `MIRA_V2`): чтение памяти, задач, календаря, Todoist, почты, соцсетей; запись через карточки с кнопками. Доступна в личке бота, в тредах (создаются фразой в чате, v4.76), из мини-приложения и из «чёлки» MacBook (v4.62). Короткое «ок / спс / 👍» после не-вопроса получает ответ без вызова модели (v4.97).

**Мини-приложение** (`https://mira.sncont.com/`, кнопка меню «Mira»). 5 вкладок, «Открытия» с примерами фраз, подключения, скиллы, выключатели «Что делает сама», «Что Мира помнит», экран «Модерация», фото контактов во вкладке «Люди».

**Виджеты в чате (v4.106–v4.107).** Карточки-страницы Bot API 10.4 прямо в личке: «Мой день» (`/day`), «Привычки» (`/habits`), «Рынок» (`/market`), а также «Черновик ответа» и «Встреча», которые приходят сами. Нажатия внутри закрывают задачи, отмечают привычки, отправляют или переписывают черновик, сдвигают встречу. С 14.11.2026 Telegram не пускает виджеты от ботов: то же приходит текстом, встреча — с кнопками сдвига, а «Рынок» и «Мой день» открываются в мини-приложении по кнопке из чата (v4.110–v4.112).

**Стримы и модерация.** Мира сидит в чате Twitch (аккаунт miraninja38) и YouTube (канал MiraNinja): отвечает на упоминание, по команде пишет, даёт таймаут и бан, держит режимы чата YouTube. В обсуждении канала @St4rNinja38 модерирует комментарии, сама удаляет явный спам, приветствует новичков. На старте стрима присылает анонс для канала (публикация кнопкой), после стрима один «🎬 Итог стрима». Основная модерация чатов по решению владельца остаётся на Nightbot / StreamElements и AutoMod.

**Финансы.** Подписки и списания (`/subs`), блок «📈 Рынок» с новостями Perplexity в утренней сводке, просмотр кошелька TON. Советов, торговых идей, сделок и переводов нет.

**Скиллы и рутины.** Каталог из 19 скиллов (`core/skills.py`: дайджест, подготовка к встрече, отчёт по контенту, идеи для YouTube, разбор рилса, рынок, новости финансов и др.) плюс свои, созданные фразой в чате. Рутины (`core/routines.py`, v4.72): напоминания готовой фразой и поручения по расписанию (once / daily / weekly / monthly / каждые N часов), поручения работают только с инструментами чтения. Автосообщения: утренняя сводка 09:00, дневное напоминание 14:00 только при поводе, вечерний итог, справки перед встречами, вопросы по контент-доске, сводки групп 21:00; каждое выключается в приложении (`core/autonomy.py`).

## Модели

| Роль | Модель | Где используется |
|---|---|---|
| Лёгкая | `claude-haiku-5-5` (`ANTHROPIC_MODEL`, с v4.63) | классификация, судьи «сделано / переоткрыть», фото, догадка роли, модерация комментариев, ответы в чатах стримов, веб-поиск |
| Умная | `claude-sonnet-5-5` (`ANTHROPIC_MODEL_SMART`, с v4.61) | извлечение задач, память, уточнения, проверка «кто делает», Mira, Mira в группах |

У Haiku 5.5 мышление выключено (`llm.adapt_params`, `max_tokens` ×2, минимум 600), поэтому в JSON-ответах причина стоит раньше вердикта (v4.81). Sonnet 5.5 в фоне идёт с `SMART_EFFORT=low`, Mira с адаптивным мышлением `MIRA_EFFORT=low`. Opus 5.5 для диалога Миры проверялся в v4.61.2 (14/15 против 11/15 у Sonnet), владелец решил остаться на Sonnet 5.5. Откат умной модели — `ANTHROPIC_MODEL_SMART` в `.env`. Месячный стоп-кран `ANTHROPIC_MONTHLY_BUDGET` (на проде 60, v4.79). При 401/403 от Anthropic владелец получает тревогу, после восстановления «✅ Claude снова отвечает» (v4.66).

_Расход всего бота по замеру v4.93 — около $32 за 30 дней, из них около 85% память и извлечение задач._

## Как обрабатывается входящее

```
Входящее сообщение (Telegram Business)
        │
        ▼
1. Пишет сам владелец? → авто-whitelist собеседника, проверка дат в ответе,
   ответ на задачу «ответить/скинуть» запускает проверку выполнения
        │ (нет — входящее)
        ▼
2. Тип контента: текст / голос / фото / документ
   • голос и кружки → faster-whisper small в отдельном процессе (бесплатно)
   • фото → описание Haiku 5.5 (даты, суммы, имена переписываются дословно)
   • документ → текст (PDF/DOCX/TXT)
        │
        ▼
3. КЛАССИФИКАЦИЯ: правила (regex, $0) → Haiku 5.5
   SPAM / BUSINESS / FRIEND / UNCLEAR
        │
        ▼
4. ИЗВЛЕЧЕНИЕ ЗАДАЧ после 10 минут тишины (Sonnet 5.5)
   • без сиюминутных дел и без просьб владельца к собеседнику
   • проверка «кто делает»: чужое дело → карточка «Всё равно поставить»
   • Todoist (+ Calendar, если есть время), карточка владельцу
        │
        ▼
5. ПАМЯТЬ контакта (Sonnet 5.5, выборка по смыслу CONTACT_MEMORY_SLICE)
   • записи с датой, источником и «кто сказал»
   • обещания; закрытие задачи снимает обещание
        │
        ▼
6. Mira использует всё это в разговоре и в сводках
```

## Два режима работы

| Режим | Поведение |
|-------|-----------|
| **observe** (по умолчанию) | Только наблюдает: классифицирует, ставит задачи, ведёт память. **Никому не отвечает.** |
| **active** | Плюс авто-ответы на спам и шаблон для BUSINESS. |

Переключение: `/mode active` или `/mode observe`, сохраняется в БД.
