## ⚡ Быстрый старт (шпаргалка)

**Проверить статус:** напиши боту `/health`
**Посмотреть статистику:** `/stats`
**Исправить категорию:** `/correct @username BUSINESS`
**Память на человека:** `/about @username`
**Поиск по переписке:** `/find слово`
**Включить авто-ответы:** `/mode active`
**Mira в чатах стримов:** `/twitch`, `/youtube`
**Всё остальное:** кнопка меню «Mira» → мини-приложение

**Логи на сервере** (VDSina, Амстердам, ssh-алиас `sn-ams`):
```bash
ssh sn-ams "journalctl -u tg-sorter -f"
```

**Перезапуск:**
```bash
ssh sn-ams "systemctl restart tg-sorter"
```

## 🎯 Что бот делает (в одном предложении)

Подключается к личному Telegram через Business API, классифицирует входящие, извлекает задачи и обещания в **Todoist + Google Calendar**, ведёт память каждого контакта, а ассистент **Mira** по просьбе и по расписанию работает с делами, почтой, соцсетями, чатами стримов и рынком — всё наружу только по кнопке владельца.
