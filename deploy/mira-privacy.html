Политика конфиденциальности Mira

Privacy policy · обновлено 4 ноября 2026

Кто пользуется

Mira — частный ассистент одного человека, владельца каналов st4rninja38. Другим пользователям приложение не предлагается, вход через Google выполняет только владелец.

Какие данные Google и YouTube используются

  • Канал ассистента (MiraNinja): чтение сообщений живого чата трансляций владельца, отправка сообщений и модерация (удаление, таймаут, бан) по команде владельца.
  • Канал владельца: статистика YouTube Analytics его собственного канала (просмотры, время просмотра, подписчики, источники трафика, обобщённая демография) для личных отчётов.

Данные зрителей ограничены тем, что они сами публикуют в чате трансляции: отображаемое имя, ID канала и текст сообщения. История чата хранится в памяти сервера до его перезапуска, журнал действий модерации — 30 дней.

Хранение и передача

Данные хранятся на частном сервере владельца. Они не продаются, не передаются третьим лицам и не используются для рекламы. Для коротких ответов в чате и сводок текст сообщений отправляется в API Anthropic (Claude) только для обработки.

Как отозвать доступ

Доступ отзывается в настройках аккаунта Google: myaccount.google.com/permissions. После отзыва токены перестают работать.

Сервисы Google и YouTube

Приложение использует YouTube API Services. Пользуясь им, вы соглашаетесь с Условиями использования YouTube. Данные обрабатываются также по Политике конфиденциальности Google.

English summary

Mira is a private assistant used only by its owner. It reads and moderates the owner's YouTube live chat and reads YouTube Analytics of the owner's own channel. Data stays on the owner's private server, is never sold or shared, and is not used for ads. Revoke access at myaccount.google.com/permissions. Uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
