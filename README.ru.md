# Mira — личный ИИ-ассистент в Telegram

[English version](README.md)

Mira — ИИ-ассистент одного владельца, работает как Telegram-бот ([@Sort38_bot](https://t.me/Sort38_bot)). В июне 2026 он начинался как сортировщик сообщений Telegram Business, а вырос в ассистента, которым я пользуюсь каждый день. Он читает деловые переписки, превращает просьбы людей в задачи, помнит, кто есть кто, пишет черновики ответов в моём стиле и модерирует чаты моих стримов на Twitch и YouTube.

Это публичный снимок кода из продакшена. Реальные данные, адрес сервера, мои личные id и недоделанные части (голосовые звонки, закрытый дашборд, синхронизация с Obsidian) убраны. Бот отвечает только владельцу, поэтому публичного демо нет.

## Что умеет

- **Разбор входящих.** Каждое сообщение Telegram Business сначала проходит дешёвые правила на регулярках, потом Claude Haiku. Итог: SPAM, BUSINESS, FRIEND или UNCLEAR, у каждой категории своё действие.
- **Задачи из переписки.** Когда чат затихает на 10 минут, отдельный проход читает тред через Claude Sonnet и достаёт задачи и обещания. Они уходят в Todoist и Google Calendar без дублей. Следующие проходы закрывают выполненное и переоткрывают вернувшееся.
- **Память о контактах.** О каждом человеке Мира ведёт структурную память: факты по разделам, хронологию, стиль письма и роль. Новое вливается диффом (добавить или снять запись), индексируется локальными эмбеддингами и попадает в промпт нужным срезом, а не всей историей.
- **Агент в личке.** В личном чате Мира работает циклом с инструментами: задачи, календарь, память, почта, веб-поиск, Twitch, YouTube и другие. Поверх него каталог готовых скиллов и рутины по расписанию.
- **Черновики ответов** в моём стиле, который она выучила по моим исходящим сообщениям.
- **Стримы.** Когда эфир начинается, Мира готовит карточку-анонс (рисует Pillow) и по одному нажатию публикует её в канал. Пока идёт эфир, она обновляет пост, а в конце превращает его в карточку «Запись эфира» со ссылками на записи. Ещё она модерирует чаты Twitch и YouTube и отвечает на упоминания.
- **Мини-приложение.** Telegram Web App (`webapp/index.html`): мой день, люди, скиллы, подключения и настройки.

## Инженерия вокруг LLM

- **Выбор модели под задачу.** Haiku 5.5 — классификация, судьи «да/нет», модерация; Sonnet 5.5 — извлечение задач, память и агент. Модели задаются в конфиге.
- **Вердикт после причины.** У Haiku выключено расширенное мышление, поэтому в каждом JSON-ответе поле с причиной стоит раньше вердикта.
- **Контроль расходов.** Месячный лимит бюджета, правила до вызова LLM, пакетные вызовы судей.
- **Идемпотентность.** Перед созданием ищем существующее по стабильному ключу, плюс страховочная проверка по названию и дню: повторы не плодят дубли задач.
- **Приватность.** Номера карт маскируются до записи в базу (`core/redact.py`, проверка Луна); по флагу личные данные маскируются и перед отправкой в облако.
- **Evals.** `eval_extraction.py` — регресс-набор обезличенных кейсов извлечения задач, гоняется перед каждой правкой промпта. `mira_eval.py` — 15 диалоговых сценариев для агента с Haiku-судьёй по рубрике. `eval_done.py` и `eval_executor.py` проверяют судей «сделано ли» и «кто делает», а `eval_real_threads.py` прогоняет настоящие треды из базы (только чтение, текстов переписок в репозитории нет).
- **Разработка с Claude Code.** `CLAUDE.md` и `.claude/skills/` — это настоящие рабочие правила и регламенты (деплой, диагностика только на чтение, безопасные правки прода, релиз), по которым работает ИИ-агент в этом проекте.

## Стек

Python 3 (проверено на 3.14), aiogram 3, Anthropic SDK, SQLite (WAL) через aiosqlite, aiohttp для API мини-приложения, fastembed для локальных эмбеддингов, faster-whisper для голосовых, Pillow для карточек. Интеграции: Todoist, Google Calendar, Notion (выводится из работы), Twitch, YouTube, Gmail. Работает на небольшом VPS с Ubuntu под systemd.

Около **30 000 строк** на Python, **306 юнит-тестов**.

## Запуск

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # обязательны BOT_TOKEN, OWNER_USER_ID, ANTHROPIC_API_KEY
python main.py            # при первом запуске создаст data/bot.db
```

Бота создай в [@BotFather](https://t.me/BotFather) и включи Business Mode, потом подключи его в Telegram: Настройки → Telegram Business → Чат-боты. Свой id можно узнать у [@userinfobot](https://t.me/userinfobot).

Тесты:

```bash
BOT_TOKEN=1:x OWNER_USER_ID=1 ANTHROPIC_API_KEY=test python -m unittest tests.test_core
```

Подробная документация лежит в `docs/`: архитектура, функции, команды, интеграции, деплой и журнал разработки.
